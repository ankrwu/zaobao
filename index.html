    # 项目背景

    光伏行业作为新能源领域的重要组成部分，发展日新月异。无论是从业者、投资者还是关注绿色能源的人士，都需要及时了解行业最新动态。

    本项目整理光伏行业每日要闻，帮助大家快速获取有价值的信息。

    行业门户网站

    • 光伏们 (opens new window) - 光伏行业深度报道
    • 光伏资讯 (opens new window) - 光伏行业资讯平台
    • 北极星太阳能光伏网 (opens new window) - 光伏行业综合门户

    行业协会与机构

    • 中国光伏行业协会 (CPIA) (opens new window) - 行业数据、标准规范
    • 中国可再生能源学会 (opens new window) - 学术研究、技术交流

    政策与数据来源

    • 国家能源局 (opens new window) - 光伏政策、发展规划
    • 国家发改委新能源政策 (opens new window) - 宏观政策、补贴政策

    # 安装

    下载源码, 请执行下列命令：

    # 克隆代码
$ git clone https://github.com/ankrwu/zaobao.git
$ cd zaobao

    代码下载完成后, 需要安装依赖：

    # 安装依赖
$ npm install

# 检查是否符合文档规范
$ npm run lint:md

# 开始阅读
$ npm run doc:dev

    在浏览器中打开 http://localhost:8080/zaobao/ (opens new window)

    # 更新

    在 zaobao 文件夹中运行下面的命令就会从 GitHub 仓库拉取最新版本。

    # 拉取代码
$ git pull
